PS DU FICHIER : domain/history.py

BUT :
- Stocker l’historique des calculs directement dans state.history_items
- Chaque élément d’historique est un HistoryItem (expr, result_text, result_value)
- On ne persiste rien : c’est juste en RAM (mémoire du programme)



fonction history_add(state: AppState, expr: str, result_text: str, result_value: float) -> AppState:
    # Objectif : ajouter une ligne à l’historique

    1) item = create_history_item(expr, result_text, result_value)
       # create_history_item retourne un HistoryItem normalisé (mêmes champs)

    2) state.history_items.append(item)
       # on ajoute à la fin de la liste

    3) retourner state



fonction history_clear(state: AppState) -> AppState:
    # Objectif : supprimer tout l’historique

    1) state.history_items = []
       # on remplace par une nouvelle liste vide

    2) retourner state



fonction history_select(state: AppState, index: int) -> (AppState, str):
    # Objectif : quand l’utilisateur clique sur une ligne de l’historique,
    # on remet l’expression correspondante dans la zone de saisie.

    1) Vérifier si index est valide :
       SI index < 0 OU index >= len(state.history_items) ALORS

           a) state.message_text = "Élément d'historique introuvable."
           b) state.message_type = "error"
           c) state.error_mode = True

           d) retourner (state, "")

    2) Récupérer l’expression de l’élément demandé :
       expr = state.history_items[index].expr

    3) Mettre l’expression dans la calculatrice :
       state.expression_text = expr
       state.display_text = expr

    4) Nettoyer les messages et flags (retour à un état normal) :
       state.message_text = ""
       state.message_type = ""
       state.error_mode = False

       state.after_result = False
       state.recall_history = True
       # (on indique qu’on vient de rappeler depuis l’historique)

    5) retourner (state, expr)
